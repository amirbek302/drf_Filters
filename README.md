## 📋 О проекте

**Filter Project** — это практическое задание, направленное на отработку навыков работы с массивами данных, алгоритмами поиска и вывода данных.

### ✨ Основной функционал
* **Быстрый поиск** — мгновенная фильтрация элементов по ключевым словам.
* **Фильтрация по параметрам** — удобная выборка данных по параметрам(title/author/category).
* **Сортировка** — упорядочивание результатов (по алфавиту, дате или значению).
* **Сброс фильтров** — возврат к исходному состоянию в один клик.

## 🚀 Как запустить проект

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   ```

2. **Перейдите в папку с проектом:**
   ```bash
   cd drf_test_Filters_not_this
   ```

3. **Запустите проект:**
   ```bash
   python main.py run server
   ```
